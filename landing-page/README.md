# Landing page personal

Página de presentación responsive con sección de servicios y formulario de contacto validado.

## Tecnologías
HTML5 semántico, CSS3 (variables, Flexbox, Grid), JavaScript básico.

## Funcionalidades
- Diseño adaptable a móvil, tableta y escritorio
- Formulario con validación nativa del navegador
- Estados de foco visibles para accesibilidad

## Cómo ejecutarlo
Abre `index.html` en el navegador o visita la demo: ENLACE_DEMO

## Autoría y uso de IA
Proyecto desarrollado para el módulo IPE II con apoyo de una herramienta de IA para el código base.
